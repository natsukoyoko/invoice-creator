# Invoice Creator / 請求書作成アプリ

A bilingual (English/Japanese) invoice creation web application for external partners of LIFE PEPPER. Replaces manual Google Sheets templates with a system that enforces validation, handles Japanese withholding tax calculations, and optimizes for A4 printing.

## Tech Stack

- **Framework**: Hono (lightweight web framework)
- **Frontend**: Vanilla JS/JSX with Tailwind CSS (CDN)
- **Runtime**: TypeScript
- **Build Tool**: Vite with @hono/vite-dev-server and @hono/vite-build
- **Target Platform**: Cloudflare Pages (build output)
- **Package Manager**: npm

## Project Structure

```
src/
  index.tsx       # Main Hono app + all frontend logic (~2500 lines)
  renderer.tsx    # Hono JSX renderer configuration
public/
  images/         # Brand assets (lifepepper-logo.png)
  static/         # Static CSS (style.css)
dist/             # Build output (generated by vite build)
vite.config.ts    # Vite configuration (port 5000, host 0.0.0.0)
wrangler.jsonc    # Cloudflare Pages configuration
```

## Development

- **Dev server**: `npm run dev` — runs on port 5000
- **Build**: `npm run build` — outputs to `dist/`

## Key Features

- Bilingual labels (English/Japanese)
- Withholding tax calculation: 10.21% domestic, 20.42% foreign residents
- Staff list and department master data (hardcoded)
- LocalStorage persistence for issuer/payment info
- A4 print optimization via CSS media queries

## Deployment

- Configured as static site deployment
- Build command: `npm run build`
- Public directory: `dist`
